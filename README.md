 ✨ Overview

TechWave is a stylish podcast platform landing page designed to deliver an engaging user experience across all devices.
The website includes a modern hero section, podcast episode showcase, statistics section, feature highlights, and host profile section with smooth responsive behavior.


🚀 Features

 🧭 Responsive Navigation

* Modern desktop navbar layout
* Mobile hamburger menu
* Gradient call-to-action button
* Fully responsive across all screen sizes

 🎧 Hero / Banner Section

* Attractive podcast-themed background
* Centered podcast visual design
* Interactive call-to-action buttons
* Clean typography and visual effects

 📊 About Section

* Informative statistics layout
* Responsive grid structure
* Balanced spacing and alignment

 💡 Why Choose Us
